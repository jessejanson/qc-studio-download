# QC Studio for Mac

Installers for **QC Studio**, automated quality control for movies and TV on your Mac.

**[Download the latest version](https://github.com/jessejanson/qc-studio-download/releases/latest/download/QC-Studio.dmg)**

Requires a Mac with Apple silicon (M1 or later) running macOS 14 or newer. The app is signed and notarized by Apple.

1. Open `QC-Studio.dmg` and drag **QC Studio** to **Applications**.
2. Open QC Studio. On first launch it downloads its speech and sound models (about 3 GB, one time).
3. Sign in, then drop in a video.

Website: https://qcstudio-service.onrender.com · Support: jesse@janson.com

This repository only hosts installers; the source code is private.
